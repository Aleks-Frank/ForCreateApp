Почему HashMap выигрывает у двойного цикла (O(n) против O(n²))?

При двойном цикле программа дважы проходжиться по одним и темже данным, отсюдогого и получается сложность n*n. В свою очередь решение с HashMap убирает одиен цикл.
В результате получается, что одним циклом проверяются все данные, в нем же высчитывается необходимое число для суммы, проверяется, есть ли такое значение в HeshMap, что занимает O(1),
из-за этого алгоритм работает быстрее. 

Время работы в LeetCode не может показать различие во времени, так как примеры, которые он обрабатывает, имеют не большие значения и расчитывает их быстро.
